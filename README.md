## Как запускать

Каждая программа запускается из своей папки:

```text
cd lab01
python profile.py
```

Автоматические проверки (работы 7–12):

```text
cd lab07
python test_functions.py
```

Программы, читающие данные из файла, берут его рядом со скриптом
(`Path(__file__).resolve().parent`), поэтому абсолютные пути не нужны.

### Запуск в Windows

В консоли Windows перед запуском полезно включить вывод в UTF-8, чтобы
кириллица не зависела от кодовой страницы:

```text
set PYTHONIOENCODING=utf-8
python main.py
```

В IDLE и в среде разработки с настройкой UTF-8 этого не требуется.
