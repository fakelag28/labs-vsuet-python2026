## Как запустить

Нужен Python 3.13 или 3.14. Проверка версии:

```text
python --version
```

Запуск программы из папки `lab01`:

```text
python hello.py
python profile.py
python workload.py
python debug.py
python swap.py
python variant.py
```

В Windows из Git Bash удобно подавать входные данные сразу, чтобы не
вводить их вручную. Пример для `profile.py`:

```bash
cd "C:/Users/Fakel/Desktop/github/labs-vsuet-python2026/lab01" && \
printf 'Иванов\nИван\nИС-11\nВоронеж\n17\nМатематика\n10.5\n' | PYTHONIOENCODING=utf-8 python profile.py
```

## Ответы на вопросы к защите

- **Строка и число.** `input()` всегда возвращает строку (`str`). Строки
  склеиваются операцией `+` («2» + «3» даёт «23»), а не складываются как
  числа. Чтобы получить число, применяют `int()` или `float()`: после
  `int("2") + int("3")` получается `5`.
- **Порядок вычислений.** Сначала выполняются умножение и деление, потом
  сложение и вычитание; скобки меняют порядок. Поэтому в фрагменте В
  `first + second + third / 3` считалось как `4 + 7 + 10/3`, и результат был
  неверным; правильная запись — `(first + second + third) / 3` = `7.0`.
- **Временная переменная при обмене.** Значение первой переменной сначала
  сохраняют в третью, иначе оно потерялось бы при перезаписи: `temp_room =
  first_room; first_room = second_room; second_room = temp_room`.
- **Форматирование денежного вывода.** `:.2f` внутри f-строки выводит число
  с двумя знаками после точки, то есть в рублях и копейках: `{cost:.2f}`.
