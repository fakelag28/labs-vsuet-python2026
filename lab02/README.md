# Лабораторная работа 2. Вычисления и проверка результата

Вариант 1: «Количество студентов / Мест в автобусе».

## Файлы

- `time_parts.py` — перевод секунд в часы, минуты и секунды.
- `purchase.py` — стоимость покупки и сдача.
- `variant.py` — вариант 1: заполненные автобусы, остаток и минимальное число автобусов.

## Задание 3. Прогноз результата

Прогноз, сделанный вручную до запуска:

| Выражение | Прогноз | Результат Python |
|---|---|---|
| `2 + 3 * 4` | 14 | 14 |
| `(2 + 3) * 4` | 20 | 20 |
| `17 // 5` | 3 | 3 |
| `17 % 5` | 2 | 2 |
| `-7 // 2` | -4 | -4 |

Все прогнозы совпали с результатом Python, различий нет.

- `2 + 3 * 4 = 14`: сначала умножение (`3 * 4 = 12`), потом сложение.
- `(2 + 3) * 4 = 20`: скобки меняют порядок, сложение выполняется первым.
- `17 // 5 = 3`: деление с округлением вниз, целая часть.
- `17 % 5 = 2`: остаток от деления (`17 = 3 * 5 + 2`).
- `-7 // 2 = -4`: округление идёт вниз (к минус бесконечности), а не к нулю. Проверка: `-4 * 2 + 1 = -7`, остаток `-7 % 2 = 1`.

## Выводы

- `/` даёт вещественный результат (`7 / 2 = 3.5`), а `//` — целую часть с округлением вниз.
- Остаток `%` показывает, что не уместилось в целую часть: `a == (a // b) * b + a % b`.
- Формат `:.2f` меняет только вывод, но не хранимое значение, поэтому неточность `float` не устраняет.
