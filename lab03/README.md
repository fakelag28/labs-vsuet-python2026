# Лабораторная работа 3. Условия и логические выражения

Вариант 1 — «Заряд аккумулятора».

## Файлы

| Файл | Задание |
| --- | --- |
| `minimum.py` | Минимум трёх чисел через `if`/`elif`/`else` |
| `calculator.py` | Калькулятор: `+`, `-`, `*`, `/` |
| `point.py` | Принадлежность прямоугольнику `0 <= x <= 5`, `0 <= y <= 3` |
| `variant.py` | Вариант 1: категория заряда аккумулятора |

## Запуск

```
python minimum.py
python calculator.py
python point.py
python variant.py
```

Порядок ввода в `calculator.py`: первое число, второе число, операция.
При вводе из консоли с кириллицей на Windows: `set PYTHONIOENCODING=utf-8`.

## Проверки: ввод → ожидаемый ответ → фактический ответ

### minimum.py

| Ввод | Ожидаемый ответ | Фактический ответ |
| --- | --- | --- |
| `2`, `10`, `3` | Минимум: 2 | Минимум: 2 |
| `5`, `5`, `5` | Минимум: 5 | Минимум: 5 |
| `-4`, `0`, `-2` | Минимум: -4 | Минимум: -4 |
| `7`, `3`, `1` (минимум в конце) | Минимум: 1 | Минимум: 1 |

### calculator.py

| Ввод | Ожидаемый ответ | Фактический ответ |
| --- | --- | --- |
| `7`, `2`, `/` | Результат: 3.50 | Результат: 3.50 |
| `5`, `0`, `/` | Деление на ноль запрещено | Деление на ноль запрещено |
| `5`, `2`, `?` | Неизвестная операция | Неизвестная операция |
| `2`, `3`, `+` | Результат: 5.00 | Результат: 5.00 |

## Пояснения к защите

- В `minimum.py` используются только ветвления: первая подходящая ветвь выбирает
  минимум, при равенстве значений срабатывает самая первая проверка.
- В `calculator.py` цепочка `elif` гарантирует, что выполнится ровно одна ветвь.
  Проверка деления на ноль стоит внутри ветви `/`, поэтому сообщение выводится
  только для этой операции.
- В `point.py` условие соединяет два неравенства через `and`: точка внутри, когда
  обе координаты попадают в свои отрезки. Запись `0 <= x <= 5` включает границу.
- В `variant.py` диапазон проверяется первым через `or`; затем `elif` делят
  допустимые значения по возрастанию порогов, поэтому каждый интервал включает
  свои концы.
