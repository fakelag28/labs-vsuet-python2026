# Лабораторная работа 4. Циклы, счётчики и накопители

Работы: обязательные задания 1–3 и индивидуальный вариант 1 («Чётные числа»).

## Файлы

| Файл | Задание |
| --- | --- |
| `range_numbers.py` | Задание 1. Вывод чисел от `a` до `b` в нужном направлении |
| `statistics.py` | Задание 2. Сумма, число положительных и максимум для `n` чисел |

| `variant.py` | Вариант 1. Количество и сумма чётных чисел |

## Запуск

```bash
python range_numbers.py
python statistics.py
python positive_input.py
python variant.py
```

Числа вводятся по одному в ответ на приглашение.

## Таблица значений накопителя

Цикл суммирования чисел от 1 до 4 (`range(1, 5)`), переменная `total`
начинается с нуля и увеличивается на очередное число:

| Момент | Число `number` | `total` после операции |
| --- | --- | --- |
| До первой итерации | — | 0 |
| После 1-й итерации | 1 | 1 |
| После 2-й итерации | 2 | 3 |
| После 3-й итерации | 3 | 6 |
| После 4-й итерации | 4 | 10 |

Значение `total` до первой итерации равно `0` (инициализация), затем
последовательно принимает значения `1`, `3`, `6`, `10`.

## Почему цикл завершается

`for` перебирает конечную последовательность `range(a, b + step, step)`:
число элементов ограничено, поэтому цикл обязательно завершится. В
`positive_input.py` условие `while` зависит от переменной `number`,
которая обновляется в теле цикла, — рано или поздно пользователь введёт
положительное число, и цикл закончится.

## Почему `range(a, b)` не всегда подходит

`range(a, b)` идёт с шагом по умолчанию `+1` и не включает `b`. Для
задания 1 нужно включить `b`, а при `a > b` двигаться вниз. Поэтому
направление задаётся шагом `step` (`+1` или `-1`), а верхняя граница
берётся как `b + step`, чтобы `b` попало в последовательность.
