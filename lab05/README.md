# Лабораторная работа 5. Обработка строк

Индивидуальный вариант: **Вариант 1 — «Начинается с а»**.

## Файлы

| Файл | Назначение |
| --- | --- |
| `normalize.py` | Нормализация текста: убрать пробелы по краям, сжать внутренние до одного |
| `palindrome.py` | Проверка текста на палиндром (регистр и обычные пробелы игнорируются) |
| `replace.py` | Замена всех двоеточий на дефисы с подсчётом вхождений |
| `variant.py` | Вариант 1: слова, начинающиеся с буквы «а» |

## Запуск

```
PYTHONIOENCODING=utf-8 python normalize.py
```

Ввод подаётся на стандартный ввод. Пример для Windows (bash):

```
cd "C:/Users/Fakel/Desktop/github/labs-vsuet-python2026/lab05" && printf '  Один   два  \n' | PYTHONIOENCODING=utf-8 python normalize.py
```

## Пояснения

- **Нормализация.** `text.split()` без аргументов делит строку по любым пробельным символам и отбрасывает пустые части, поэтому `" ".join(text.split())` сразу убирает пробелы по краям и сжимает внутренние последовательности до одного пробела. Регистр не меняется.
- **Палиндром.** Обычные пробелы удаляются через `replace(" ", "")`, регистр приводится к нижнему через `lower()`. Остальные символы (включая пунктуацию) сравниваются как есть. Сравнение идёт со срезом `[::-1]`. Пустая очищенная строка даёт `Нет текста`.
- **Замена.** Сначала `text.count(":")` считает вхождения в исходном тексте, затем `text.replace(":", "-")` выполняет замену.
- **Вариант 1.** Строка делится по пробельным через `split()`. У каждого слова с обоих краёв снимаются символы `.,!?;:` методом `strip(".,!?;:")`, результат переводится в нижний регистр. Пустые результаты пропускаются. Начало слова проверяется через `startswith("а")` только после пропуска пустых слов.
