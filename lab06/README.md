# Лабораторная работа №6. Списки и обработка наборов данных

Все программы читают целые числа одной строкой через пробел и не используют классы и лямбды.
Списковые включения допустимы, но в каждой программе показан эквивалентный цикл с `append()`
(в `transform.py` и `variant.py` рядом с циклом в комментарии приведён эквивалент включением).

## Файлы

| Файл | Задание |
| --- | --- |
| `statistics.py` | Количество, сумма, минимум, максимум, среднее (2 знака) |
| `transform.py` | Новый список с модулями отрицательных; исходный сохраняется |
| `positions.py` | Все индексы максимума по возрастанию (через `enumerate()`) |
| `variant.py` | Вариант 1 «Чётные числа» |

## Команды запуска

Запуск выполняется с `PYTHONIOENCODING=utf-8` из каталога `lab06`:

```bash
printf -- '-2 0 5 3\n'      | PYTHONIOENCODING=utf-8 python statistics.py
printf -- '8\n'             | PYTHONIOENCODING=utf-8 python statistics.py
printf -- '\n'              | PYTHONIOENCODING=utf-8 python statistics.py
printf -- '-2 0 5 -2\n'     | PYTHONIOENCODING=utf-8 python transform.py
printf -- '3 7 2 7\n'       | PYTHONIOENCODING=utf-8 python positions.py
printf -- '7 7\n'           | PYTHONIOENCODING=utf-8 python positions.py
printf -- '-3 -1 -2\n'      | PYTHONIOENCODING=utf-8 python positions.py
printf -- '-8 -3 0 6 6 1\n' | PYTHONIOENCODING=utf-8 python variant.py
printf -- '-3 1 5\n'        | PYTHONIOENCODING=utf-8 python variant.py
```

## Таблица проверок

### statistics.py

| Ввод | Количество | Сумма | Минимум | Максимум | Среднее |
| --- | --- | --- | --- | --- | --- |
| `-2 0 5 3` | 4 | 6 | -2 | 5 | 1.50 |
| `8` | 1 | 8 | 8 | 8 | 8.00 |
| пустая строка | — | — | — | — | `Нет данных` |

Фактический вывод для `-2 0 5 3`:

```
Количество: 4
Сумма: 6
Минимум: -2
Максимум: 5
Среднее: 1.50
```

Фактический вывод для `8`:

```
Количество: 1
Сумма: 8
Минимум: 8
Максимум: 8
Среднее: 8.00
```

Фактический вывод для пустой строки:

```
Нет данных
```

При пустом вводе `min()`/`max()` не вызываются и деления на ноль не происходит.

### transform.py

| Ввод | Исходный список (до) | Новый список | Исходный список (после) |
| --- | --- | --- | --- |
| `-2 0 5 -2` | `[-2, 0, 5, -2]` | `[2, 0, 5, 2]` | `[-2, 0, 5, -2]` |
| пустая строка | `[]` | `[]` | `[]` |

**Доказательство сохранения исходного списка:** программа печатает исходный список дважды —
до и после построения нового. В обоих случаях для `-2 0 5 -2` он равен `[-2, 0, 5, -2]`.
Новый список строится отдельно через `append()` и не изменяет `source`.

Фактический вывод для `-2 0 5 -2`:

```
Исходный список: [-2, 0, 5, -2]
Новый список: [2, 0, 5, 2]
Исходный список сохранён: [-2, 0, 5, -2]
```

### positions.py

| Ввод | Максимум | Индексы максимума |
| --- | --- | --- |
| `3 7 2 7` | 7 | `[1, 3]` |
| `7 7` | 7 | `[0, 1]` |
| `-3 -1 -2` | -1 | `[1]` |
| пустая строка | — | `Нет данных` |

Максимум определяется один раз через `max()`, затем список обходится с `enumerate()`,
поэтому индексы идут в порядке возрастания.

Фактический вывод для `3 7 2 7`:

```
Максимум: 7
Индексы максимума: [1, 3]
```

### variant.py (вариант 1 «Чётные числа»)

| Ввод | Чётные (исходный порядок) | Количество | Сумма | Отсортированная копия |
| --- | --- | --- | --- | --- |
| `-8 -3 0 6 6 1` | `[-8, 0, 6, 6]` | 4 | 4 | `[-8, 0, 6, 6]` |
| пустая строка | `[]` | 0 | 0 | `[]` |
| `-3 1 5` | `[]` | 0 | 0 | `[]` |

Фактический вывод для `-8 -3 0 6 6 1`:

```
Чётные числа: [-8, 0, 6, 6]
Количество: 4
Сумма: 4
Отсортированная копия: [-8, 0, 6, 6]
```

Фактический вывод для пустого ввода и для `-3 1 5` совпадает:

```
Чётные числа: []
Количество: 0
Сумма: 0
Отсортированная копия: []
```

## Пояснения к защите

- `append()` добавляет элемент в конец списка и меняет длину; присваивание по индексу
  `items[i] = value` заменяет уже существующий элемент, не меняя длину.
- `sorted(items)` возвращает новый отсортированный список и не меняет исходный;
  `items.sort()` сортирует список на месте и возвращает `None`.
- `copy = items` связывает два имени с одним списком, поэтому нужна отдельная копия
  (`items.copy()`) или построение нового списка, как в `transform.py`.
