# Лабораторная работа №7. Функции и автоматические проверки

Вариант 1: `select_numbers(numbers, threshold)` возвращает новый список
чисел, **строго больших** порога, сохраняя порядок и повторы.

## Состав

| Файл | Назначение |
| --- | --- |
| `functions.py` | Чистые функции: `sum_digits`, `average`, `normalize_text`, `select_numbers` |
| `main.py` | Точка входа: запрашивает данные и демонстрирует все функции |
| `test_functions.py` | Автоматические проверки базового набора и варианта |
| `README.md` | Описание и команды запуска |

## Команды запуска

Интерактивная демонстрация:

```bash
cd lab07
PYTHONIOENCODING=utf-8 python main.py
```

Автоматические проверки:

```bash
cd lab07
PYTHONIOENCODING=utf-8 python test_functions.py
```

`PYTHONIOENCODING=utf-8` задаёт кодировку ввода-вывода, чтобы русский текст
корректно читался и выводился на любой платформе.

## Возврат и вывод

`return` передаёт значение из функции вызывающему коду: его можно сохранить
в переменную и использовать дальше. `print()` только показывает текст
человеку и ничего не возвращает (результат такого вызова — `None`). Поэтому
функции в `functions.py` считают и возвращают результат, а печать сосредоточена
в `main.py`. Это позволяет проверять функции в `test_functions.py` без ввода
и вывода, сравнивая возвращённые значения с ожидаемыми.

Так же различаются локальная переменная и параметр: параметр — имя вошедших
в функцию данных, локальная переменная — временное хранилище внутри вызова.
Обе видны только внутри функции, поэтому `global` не нужен: результат
возвращается через `return`.
