# Лабораторная работа 9. Вложенные списки и таблицы

Таблица хранится как список строк: `matrix[row][column]`. Первый индекс —
номер строки, второй — номер столбца. В работе обрабатывается прямоугольная
таблица вложенными циклами.

## Файлы

- `table.py` — функции обработки таблиц без ввода и вывода:
  - `row_sums(matrix)` — список сумм строк; для `[]` возвращает `[]`.
  - `column_sums(matrix)` — список сумм столбцов; для `[]` возвращает `[]`.
    Непустая таблица прямоугольная и имеет хотя бы один столбец.
  - `diagonal_pattern(size)` — квадратная таблица размера `size >= 1`:
    на главной диагонали `0`, выше неё `1`, ниже неё `2`.
  - `transform(matrix)` — вариант 1: отрицательные элементы заменяются
    нулями. Возвращается новая таблица той же формы, исходная не меняется;
    для `[]` результат — `[]`.
- `main.py` — точка входа: ввод прямоугольной таблицы с проверкой длины
  строк, вывод сумм строк и столбцов, вывод диагонального узора, затем
  вывод исходной и преобразованной таблиц.
- `test_table.py` — проверки функций с помощью `assert`.

## Почему нельзя повторять одну изменяемую строку

Если создать таблицу как `[[0] * columns] * rows`, то все элементы внешнего
списка будут ссылаться на один и тот же внутренний список. При изменении
одной ячейки изменится сразу несколько строк, потому что строки — это не
копии, а ссылки на один объект.

Правильно создавать каждую строку отдельно, например
`[[0] * columns for _ in range(rows)]`: включение выполняется `rows` раз и
каждый раз создаёт новый список.

Похожая ошибка — `matrix.copy()`. Этот метод копирует только внешний список,
а строки внутри остаются общими. Для независимой копии таблицы чисел нужно
копировать и строки: `[row.copy() for row in matrix]`. Именно поэтому функция
`transform` создаёт новую таблицу по строкам, а не копирует внешний список.
