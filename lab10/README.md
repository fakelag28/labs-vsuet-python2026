## Формат входного файла `matrix.txt`

- Первая строка — два положительных целых числа: количество строк и столбцов.
- Далее ровно указанное число строк, в каждой ровно указанное число целых чисел.
- Числа в строке разделяются пробелами.
- Лишние и пустые строки считаются ошибкой.
- Один обычный перевод строки после последней строки данных допустим.
- Кодировка — UTF-8.

Содержимое `matrix.txt`:

```text
2 3
1 -2 3
4 0 -6
```

При нарушении формата `read_matrix` выбрасывает `ValueError` с понятным
пояснением и номером строки, если он применим. Отсутствующий файл приводит к
`FileNotFoundError` (его выбрасывает `open`).

## Формат отчёта `report.txt`

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 8
```

Третья строка — индивидуальный вариант 1 «Положительные элементы»: сумма
положительных элементов матрицы (`1 + 3 + 4 = 8`). Если подходящих элементов
нет, результат равен `0`. Индексы начинаются с нуля, условие работает для любой
прямоугольной матрицы.

## Таблица проверок (`test_files.py`)

Проверки используют `tempfile.TemporaryDirectory()`, поэтому временные файлы
создаются в отдельной папке. Для ожидаемых исключений применяется
`try`/`except ValueError`; в ветви `else` стоит `assert False, "Ошибка не обнаружена"`.

| Содержимое или ситуация | Ожидаемое поведение | Результат |
| --- | --- | --- |
| `1 2` и строка `7 -1` | матрица `[[7, -1]]` | пройдено |
| `1 1` и строка `0` | матрица `[[0]]` | пройдено |
| Пустой файл | `ValueError` | пройдено |
| Заголовок `0 3` | `ValueError` | пройдено |
| Заголовок `1 2`, строка `1` | `ValueError` с указанием строки 2 | пройдено |
| Заголовок `1 2`, строка `1 x` | `ValueError` с указанием строки 2 | пройдено |
| Заголовок `1 1`, две строки данных | `ValueError` | пройдено |
| Отсутствующий путь | `FileNotFoundError` | пройдено |

Фактический вывод тестов и код возврата:

```text
Все проверки чтения матрицы пройдены
exit=0
```

Дополнительные краевые случаи (проверены вручную):

```text
'no trailing newline'               -> OK [[0]]
'one trailing newline (ok)'         -> OK [[0]]
'extra blank line'                  -> ValueError: Строка 3: лишние строки после данных
'extra data line'                   -> ValueError: Строка 3: лишние строки после данных
'blank data line'                   -> ValueError: Строка 2: пустая строка недопустима
'too many header tokens'            -> ValueError: Строка 1: ожидалось два целых числа (строки и столбцы), получено 3
'non-integer header'                -> ValueError: Строка 1: размеры должны быть целыми числами
```

## Проверка надёжного ввода

`read_positive_integer()` повторяет ввод, пока не получено целое число больше
нуля, с разными сообщениями для нечислового ввода и для неположительного числа.

Запуск `printf 'abc\n0\n-2\n3\n' | PYTHONIOENCODING=utf-8 python main.py`:

```text
Введите целое положительное число: Это не целое число, повторите ввод
Введите целое положительное число: Число должно быть больше нуля
Введите целое положительное число: Число должно быть больше нуля
Введите целое положительное число: Принято число: 3
Отчёт записан: report.txt
```

На три неверных ввода (`abc`, `0`, `-2`) выдано три сообщения об ошибке, затем
принято число `3`. Различаются два вида сообщений, как требует задание:
«не целое число» и «должно быть больше нуля».

## Проверка сохранности старого `report.txt` при некорректном входе

Отчёт открывается на запись **только после успешной проверки всех данных**, а
входной файл всегда открывается только на чтение. Поэтому при ошибке чтения или
проверки существующий `report.txt` не изменяется.

Проверка выполнена реально: во временной папке запускалась настоящая программа
`main.py`. Сначала с корректным `matrix.txt` был создан отчёт, затем `matrix.txt`
был испорчен (в строке данных оказалось два числа вместо трёх) и программа
запущена снова. Фактический вывод:

```text
Первый запуск, код возврата: 0
report.txt после корректного входа:
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 8
---
Второй запуск (испорченный matrix.txt), код возврата: 0
Вывод программы: Введите целое положительное число: Принято число: 3
Ошибка формата данных: Строка 2: ожидалось 3 чисел, получено 2
report.txt после некорректного входа:
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта: 8
---
report.txt не изменился: True
```

Видно, что после второго запуска содержимое `report.txt` осталось прежним
(`report.txt не изменился: True`).

## Обработка ошибок в `main.py`

| Ошибка | Сообщение программы |
| --- | --- |
| Файл отсутствует | `Файл не найден: matrix.txt` |
| Неверная кодировка | `Неверная кодировка: файл должен быть в UTF-8` |
| Ошибка формата данных | `Ошибка формата данных: <пояснение с номером строки>` |
| Ошибка доступа | `Ошибка доступа к файлу: <пояснение>` |
| Ошибка записи отчёта | `Не удалось записать отчёт: <пояснение>` |

`except UnicodeError` расположен перед `except ValueError`, так как
`UnicodeDecodeError` является потомком `ValueError`; `except FileNotFoundError` —
перед `except OSError`.
