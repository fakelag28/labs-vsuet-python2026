## Формат данных

Корень JSON — список записей. Каждая запись — объект с ключами `id`
(положительное целое, уникальное), `userId` (положительное целое), `title`
(непустая строка), `completed` (логическое значение). Дополнительные ключи
допустимы. Проверка использует `type(value) is int` и `type(value) is bool`,
поэтому `true` не принимается вместо идентификатора, а строка `"false"` — вместо
логического значения.

## Обработка ошибок (фактические запуски)

| Ситуация | Фактический вывод | Данные |
|---|---|---|
| `todos.json` отсутствует | `Файл не найден: todos.json` | результаты не изменяются |
| Повреждённый JSON (`{oops`) | `Ошибка разбора JSON: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)` | результаты не изменяются |
| `completed` строкой `"false"` | `Ошибка структуры данных: Запись 1: completed должен быть True или False` | `leaders.json` не перезаписан (сравнение файлов до и после запуска: идентичны) |

`json.JSONDecodeError` — подкласс `ValueError`, поэтому его обработчик стоит
раньше общего обработчика структуры.

## HTTP-упражнение

`python fetch_profile.py`, ввод `octocat` → `Профиль сохранён: octocat`.
Запрос выполнен успешно, файл `profile.json` создан (`login: octocat`,
`id: 583231`).

- Адрес `https://api.github.com/users/<логин>` — ресурс профиля пользователя;
  логин подставляется через `quote()`, чтобы посторонние символы не попали в URL.
- Метод GET читает ресурс и не изменяет данные на сервере.
- `timeout=10` ограничивает ожидание ответа, чтобы программа не зависла.
- Обработчики: `HTTPError` (коды 403, 404, 429 и другие), `URLError`/`TimeoutError`
  (нет сети или истекло время ожидания), `ValueError`/`UnicodeError` (ответ не
  похож на профиль), `OSError` (ошибка записи файла).
- Сетевой вызов находится внутри `main()` под `if __name__ == "__main__":`,
  поэтому импорт модуля проверками не выполняет запросов к сети.
