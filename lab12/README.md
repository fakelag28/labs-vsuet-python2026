## Формат данных

`data.json` — список записей. Каждая запись содержит пять обязательных ключей:

```json
[
  {"id": 1, "title": "Математический анализ", "category": "учёба", "amount": 4, "completed": true},
  {"id": 2, "title": "Программирование на Python", "category": "учёба", "amount": 3, "completed": false}
]
```

* `id` — положительное целое, уникальное в списке;
* `title`, `category` — непустые строки после `strip()`;
* `amount` — целое не меньше нуля (логические значения не принимаются);
* `completed` — строго `bool`.

Новая запись получает идентификатор `max + 1` (для пустого списка — `1`).
Идентификаторы существующих записей после удаления не перенумеровываются.

## Контракты функций

| Функция | Изменяет список | Возвращает |
|---|---|---|
| `validate_records(records)` | нет | тот же список; `ValueError` при нарушении |
| `add_record(records, title, category, amount)` | да | добавленную запись |
| `find_records(records, query)` | нет | новый список; `ValueError` при пустом запросе |
| `find_by_id(records, record_id)` | нет | запись или `None` |
| `set_completed(records, record_id, completed)` | да | `True` при успехе, `False` если id неизвестен |
| `delete_record(records, record_id)` | да | `True` при успехе, `False` если id неизвестен |
| `statistics(records)` | нет | словарь с итогами |
| `load_records(path)` / `save_records(path, records)` | — | данные / `None`; исключения при ошибке |

Изменяемых глобальных переменных для состояния нет: список записей передаётся
аргументом.

## Результаты сценариев приёмки (фактические запуски)

| Сценарий | Ожидаемое поведение | Фактический результат |
|---|---|---|
| Файла нет | Пустой список, меню доступно | `Файл data.json не найден. Начинаем с пустого списка.` → `Нет записей` |
| JSON содержит `[]` | Список пуст, статистика нулевая | `Всего записей: 0`, `Выполнено: 0`, `Не выполнено: 0`, `Сумма запланированных часов: 0` |
| Добавлены записи с количеством 4 и 2, вторая завершена | Всего 2, выполнена 1, невыполнена 1, сумма 6 | `Всего записей: 2` / `Выполнено: 1` / `Не выполнено: 1` / `Сумма запланированных часов: 6` |
| Название введено как `  Python  ` | Сохранено `Python` | В файле `"title": "Python"` |
| Поиск `PY` при названии `Python` | Запись найдена | `Найдено записей: 1` → `1: Python | учёба | 3 ч | не выполнено` |
| Пустое название, `amount=-1`, `amount=abc` | Повторный ввод, лишняя запись не появляется | `Значение не должно быть пустым`, `Нужно целое число`, `Количество не может быть отрицательным` → добавлена ровно одна запись |
| Изменение статуса неизвестного ID | Сообщение, данные не изменены | `Запись с идентификатором 99 не найдена`, при выводе статус прежний |
| Удаление отменено (ответ `нет`) | Запись сохранена | `Удаление отменено` → запись с ID 1 осталась |
| Удалена запись с ID 1 из списка с ID 1 и 2 | Оставшаяся сохраняет ID 2, новая получает ID 3 | `Запись удалена` → в списке ID 2 → `Добавлена запись с идентификатором 3` |
| Сохранение и перезапуск | Все поля и статусы восстановлены | После перезапуска: `1: Лекция | учёба | 4 ч | не выполнено`, `2: Тренировка | спорт | 2 ч | выполнено` |
| Повреждённый JSON | Запуск прекращён, файл не изменён | `Ошибка: файл data.json повреждён: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)`; сравнение файла до и после запуска — идентичны |
| Повторный ID в файле | Запуск прекращён, файл не изменён | `Ошибка структуры данных: Запись 2: id 1 повторяется`; файл не изменён |
| Неправильная кодировка файла | Запуск прекращён | `Ошибка: файл data.json имеет неправильную кодировку, нужна UTF-8.` |
| Ошибка сохранения | Нет сообщения об успехе, работа продолжается | `Не удалось сохранить данные: [Errno 13] Permission denied: '...data.json'`; меню продолжило работу, выход после ответа `нет` |
| Неправильная команда | Сообщение и повторный показ меню | `Неизвестная команда, выберите номер от 1 до 8` и меню выводится снова |

## Автоматические проверки

```text
$ python test_logic.py
Проверки логики пройдены

$ python test_storage.py
Проверки хранения пройдены
```

`test_logic.py` проверяет: статистику обычного и пустого списка, отсутствие
изменений исходного списка в `statistics()` и `find_records()`, `id = max + 1`,
начальный статус `False`, удаление краевых пробелов, одинаковые названия с
разными `id`, поведение после удаления, поиск без учёта регистра, пустой
запрос, неизвестный `id` при изменении статуса и удалении, а также отклонение
ошибочных структур (`amount = -1`, `amount = "abc"`, `amount = True`,
`completed = 1`, пустые строки, `id = 0`, `id = True`, повторный `id`).

`test_storage.py` работает во временной папке `TemporaryDirectory()`: проверяет
отсутствие файла, сохранение и повторное чтение, пустой список, повреждённый
JSON и неправильную кодировку. Рабочий `data.json` при проверках не изменяется.
