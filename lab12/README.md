Вариант 1: план учебных занятий. Программа работает на Python 3 без внешних библиотек.

Запуск из папки lab12:

```sh
python main.py
python test_logic.py
python test_storage.py
```

Файл data.json содержит список объектов: положительный уникальный id, непустые title и category, неотрицательное целое amount (часы), логическое completed. В примере три занятия: всего 3, завершено 1, не завершено 2, запланировано 9 часов; математика — 2, программирование — 7.

Автор: не указан.

Проверены сценарии: отсутствующий файл, добавление двух записей, повторный ввод числа, поиск без учёта регистра, изменение статуса, отмена удаления, статистика, сохранение и повторная загрузка. При повреждённом JSON запуск прекращается, файл остаётся без изменений. Автоматические проверки также охватывают пустой список, повторяющиеся названия, строгие типы, неизвестные ID и удаление с сохранением идентификаторов.
